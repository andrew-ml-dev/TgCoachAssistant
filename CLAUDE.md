# Правила проекта

Личный Telegram-бот для похудения (один пользователь, интерфейс на русском). Описание функций и движка — в `PLAN.md`.

## Как работать с идеями и функциями

- **Каждую идею пользователя оценивай критически, прежде чем делать.** Скажи прямо, что в ней сработает, что нет и почему; если есть вариант проще или полезнее — предложи его и объясни разницу. Не соглашайся из вежливости.
- **Никаких функций ради функций.** Функция добавляется, только если ею удобно пользоваться каждый день. Проверка: сколько нажатий и сообщений она требует, будет ли человек делать это через месяц, что он получает взамен. Если ответ слабый — упрости или не делай.
- Предпочитай решения, где бот учится на том, что пользователь и так делает (записи еды, нажатия кнопок), а не требует отдельного ввода: анкет, опросов, длинных настроек.
- Каждый лишний вопрос, экран и кнопка — это цена. Новая кнопка должна оправдывать место в меню.
- После добавления функции честно скажи о её слабых местах.

## Ограничения

- Claude API расходуется экономно: без изображений, модель `claude-haiku-5-5`, сначала локальный кеш и расчёты, запрос к API — только когда без него нельзя.
- Бот работает на Raspberry Pi; на Mac параллельно с тем же токеном не запускать.

## Команды

- Тесты: `.venv/bin/python -m pytest -q`
- Деплой: `./deploy/deploy.sh admin@192.168.8.112` (база `data/` на Pi не затрагивается)
